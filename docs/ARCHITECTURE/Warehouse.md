# Warehouse

هر پارت انبار دوزوله با کلید ترکیبی زیر تعریف می‌شود:

`country_id + permit_type`

بنابراین دو نوع مجوز برای یک کشور، دو موجودی مستقل هستند و پیشنهاد یا تخصیص سریال هرگز نباید فقط با `country_id` انجام شود.

چرخه عمر هر سریال:

`raw → consumed → issued → collected/lost/archived`

پارت‌های قدیمی که نوع مجوزشان از داده قبلی قابل تشخیص قطعی نیستند، تا تعیین نوع مجوز توسط ادمین قابل تخصیص نیستند.
