# Iran locations dataset

The `iran-locations.json` file is derived from `sijad/iran-cities-list` and is
bundled locally so Shahbaz location forms work without a CDN or network access.

- Source: https://github.com/sijad/iran-cities-list
- License: MIT (see `LICENSE.iran-cities-list.txt`)
- Imported: 2026-07-20

The data is used as a convenience list and is not a legal substitute for the
latest official administrative-division publication.
